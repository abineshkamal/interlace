Notifications

Session headers

Added to every Repeater, active-scan and crawl request — for authenticated testing (e.g. a Cookie or Authorization header).

Login macro

Build a login sequence with the + Macro button on captured requests, then replay it here to capture session cookies automatically.

Low-privilege identity (for Authz testing)

Headers (e.g. a low-role Cookie) used by the ⚖ Authz button to replay requests as a different user.

Per-host rules

Extra headers applied only to matching hosts (exact host, .suffix for subdomains, or *). JSON array of {"pattern","headers":[{"name","value"}]}.

CSRF auto-refresh

Before each state-changing request, Interlace fetches a page, extracts a fresh anti-CSRF token and injects it — so authenticated POST/PUT/PATCH/DELETE requests aren't rejected.

Scope

Active scanning only fires at in-scope hosts. One host per line. Use *.example.com for subdomains.

Route traffic through Interlace

  1. Set your browser/tool HTTP & HTTPS proxy to 127.0.0.1:8080
  2. Click Download CA and install interlace-root-ca.pem into your trust store (Trusted Root Certification Authorities).
  3. Browse an authorized target — requests appear live.
